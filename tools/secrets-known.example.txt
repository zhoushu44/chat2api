# ============================================================
# 「已泄露密钥」硬阻断清单（模板）
#
# 用途：
#   把历史上曾经泄露、且已经轮换掉的密钥字面量逐行写在这里，
#   扫描器会以精确匹配（grep -F）方式硬阻断，防止任何文件里
#   再次出现这些值 —— 即使换了文件名、换了目录也能拦住。
#
# 使用方法：
#   1. 复制本文件为 tools/secrets-known.txt
#         cp tools/secrets-known.example.txt tools/secrets-known.txt
#   2. 把真实密钥值逐行填入（每行一个，不要加引号、不要加逗号）
#   3. tools/secrets-known.txt 已被 .gitignore 忽略，绝不入库
#
# 为什么模板里不放真实值：
#   本文件会被提交进仓库。若把真实密钥写进这里，扫描器自己就变成了
#   新的泄露点。所以真实值只允许存在于被忽略的 secrets-known.txt 中。
#
# 支持的写法：
#   * 以 # 开头的行为注释，空行忽略
#   * 其余每行视为一个字面量（含特殊字符也能精确匹配）
#   * 长度小于 6 的行会被忽略，避免误伤
# ============================================================
