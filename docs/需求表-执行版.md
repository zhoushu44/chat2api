## 四、风险项

1. tls-client 指纹与 curl_cffi 对齐——M1 真实测试最早验证。
2. 上游 429 策略变化——立即轮询多打请求属预期代价。
3. 真实号额度——用户确认可多测，注册侧持续补号。
4. SSH 曾被限流（连接过频触发），传文件用分片，大命令 single-shot。
5. 本机出口曾被 Cloudflare 质疑（裸 python-requests 403，主因缺指纹）；Go tls-client 直连当前通，本地 CONNECT 代理做保险；生产环境（服务器出口）无此问题。
6. 线上 :3000/:22 从本机暂失联（TCP 通、请求被掐），待用户确认面板侧是否正常。
